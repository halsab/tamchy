# «Тамчы»: итоговый сценарий озвучки и аудиоконструктор

**Статус:** утверждённый рабочий сценарий; 177 новых клипов ожидаются, 12 существующих интерактивных реплик сохранены

**Область:** первая версия возрастных режимов — `Төсләр`, `Хайваннар`, `Саннар`

**Формат записи:** несколько длинных мастер-аудио → последующая нарезка на короткие клипы

**Графика:** шесть нейтральных PNG-форм и шесть PNG-предметов; программная перекраска по [графическому реестру](illustrations-registry.md#9-программная-перекраска-png).

**Принцип:** не записывать все комбинации целиком; переиспользовать самостоятельные слова, грамматически готовые формы и общие части фраз.

---

# 1. Зафиксированные продуктовые решения

В этой итерации используются:

- 13 цветов;
- 39 животных;
- числа 1–10 для визуального счёта;
- числа 1–20 для распознавания числа;
- 4 цветовые механики C1–C4;
- 3 механики животных A1–A3;
- 3 числовые механики N1–N3;
- чтение не требуется;
- голоса животных не используются;
- 12 существующих интерактивных реплик, включая похвалу и мягкие повторные попытки, используются в обоих режимах; наказание и очки не добавляются.

## Важное ограничение для чисел

Количество из 11–20 отдельных предметов на телефоне **не используется как основная счётная задача**.

Поэтому:

```text
1–10  → можно считать визуальные группы предметов
1–20  → можно распознавать число по озвучке и выбирать цифру
```

N2 и N3 также используют небольшие визуальные количества, преимущественно в пределах 1–10.

# 2. Аудиоконструктор

## 2.1. Разрешено

Собирать фразу только из законченных слов или грамматически готовых словоформ.

Примеры:

```text
Кызыл + төсне тап
Аюны + сайла
Кайсысы + аю
Унҗиде + кайда
Биш + туп + булганын + тап
Ничә + боҗра + бар
Зур + кызыл + шакмакны + күрсәт
```

## 2.2. Запрещено

Не разрезать слово на:

- корень;
- окончание;
- падежный суффикс;
- слог;
- отдельный звук.

Нельзя делать:

```text
аю + ны
мәче + не
```

Нужная словоформа записывается целиком:

```text
Аюны
Мәчене
Шакмакны
Унҗидене
```

## 2.3. Манера записи конструктора

Все слова, предназначенные и для самостоятельного воспроизведения, и для склейки, записывать **нейтрально и естественно**, без слишком сильного финального падения интонации.

Перед массовой записью обязательно проверить реальные склейки:

```text
Аю + кайда?
Кайсысы + аю?
Аюны + тап.
Унҗиде + кайда?
Кайсысы + унҗиде?
Кызыл + төсне тап.
Зур + кызыл + шакмакны + күрсәт.
```

Если конкретная склейка звучит неестественно, для неё допускается отдельная цельная запись.

---

# 3. Мастер-файлы для записи

Рекомендуется записать **5 больших WAV-файлов**.

```text
master-01-colors-shapes-objects.wav
master-02-numbers.wav
master-03-animal-labels.wav
master-04-animal-target-forms.wav
master-05-common-prompts.wav
```

Правила:

1. Один голос.
2. Одинаковая дистанция до микрофона.
3. Одинаковый темп.
4. Одинаковая воспринимаемая громкость.
5. Между строками — примерно 2 секунды тишины.
6. Между подразделами — 4 секунды.
7. Номера и ID вслух не читать.
8. Исходные WAV сохранить.
9. После нарезки публиковать короткие MP3 mono.
10. Финально проверить на динамике телефона.

# 10. Рецепты игровых механик

## 10.1. Цвета — C1

Используются случайно:

```text
{color} + colors.findTail
{color} + colors.chooseTail
{color} + colors.showTail
```

Примеры:

```text
Кызыл төсне тап.
Кишер сары төсне сайла.
Күк зәңгәр төсне күрсәт.
```

---

## 10.2. Животные — младший режим и A1

Используются **все пять вариантов** в обоих возрастных режимах:

```text
{animal} + common.where
{animal.target} + common.find
{animal.target} + common.choose
{animal.target} + common.show
common.which + {animal}
```

Пример для `Аю`:

```text
Аю кайда?
Аюны тап.
Аюны сайла.
Аюны күрсәт.
Кайсысы аю?
```

# 14. N1 — число и количество

## 14.1. Озвученное число → выбрать цифру — 1–20

Используются два шаблона:

```text
common.howMany + {countObject} + common.has
```

# 17. Подтверждение правильного ответа

Существующие фразы похвалы сохраняются по [разделу 13.5 ТЗ](specification.md#135-интерактивные-реплики). Их повторная запись не требуется; возможные дополнения рассматриваются отдельно в V2-05.

После правильного ответа предусмотренная интерактивная похвала предшествует учебному значению:

```text
цвет      → color.*
животное  → animal.*
число     → number.*
```

Примеры:

```text
Кызыл
Аю
Җиде
```

Для C3 допустимо визуальное подтверждение без отдельной дополнительной речи, если составная озвучка подтверждения звучит неестественно.

# 18. Что не записывать

Не создавать отдельные записи:

- 13 полных вариантов `... төсне тап`;
- 39 × 5 полных фраз животных;
- 20 × 5 полных фраз чисел;
- каждую комбинацию цвета и формы;
- каждую комбинацию размера, цвета и формы;
- каждую комбинацию числа и считаемого объекта;
- каждую конкретную арифметическую задачу;
- каждую цветовую последовательность;
- голоса животных;
- отдельные силуэты;
- сообщения о сложности;
- названия L1/L2/L3;
- очки;
- повторную запись существующей похвалы;
- наказание за ошибку;
- `Әлифба`;
- `Табигать`;
- `3 + 2 = ?`;
- `<`, `>`, `=`.

# 22. Пути, статусы и подготовка записи

Полный машиночитаемый реестр [`src/content/v2/audio.json`](../src/content/v2/audio.json) содержит `id`, `textTt`, `path` и `master`. Для 177 новых клипов `master` — имя одного из пяти WAV; для 12 предоставленных реплик — `null`, поскольку их исходные мастера не переданы.

Исходные WAV размещаются в `assets-source/audio/tt/`, нарезанные новые MP3 — в `public/assets/audio/tt/clips/`. Каталоги подготовлены с `.gitkeep`; пустых MP3 и голосовых заглушек нет. Имя нового файла получается из Clip ID: точки и границы camelCase заменяются дефисами, затем используется нижний регистр. Например, `common.whichIn` → `common-which-in.mp3`. Точные пути закреплены в JSON и не вычисляются игровым интерфейсом.

Старые 30 учебных MP3 действующего MVP остаются по прежним путям до переключения каталога. Они не прибавляются к целевым 189 и автоматически не считаются пригодными для конструктора: нейтральную интонацию и склейки нужно проверить отдельно. Все 12 `interaction/` используются напрямую по прежним путям. Одинаковые записи не копируются под новыми именами ради полноты.

Проверка наличия не подтверждает произношение, интонацию или звук на телефоне. Происхождение существующих MP3: предоставлены владельцем; отдельные исходники и условия использования пока не переданы. Новый аудиоматериал ещё не предоставлен. Релиз v2 требует полного реального набора, декодирования, включения в precache и проверки владельцем.
