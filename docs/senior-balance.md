# Балансировка старшего режима: решение S02

Дата: 8 сентября 2026 года. Статус: правила реализованы в домене S06; полные генераторы реализованы в S07–S09, подключение к игровому экрану выполняется в S10–S11. Нормативные точки входа — разделы 5, 6 и 11 [ТЗ v2](specification.md). Это стартовые параметры, а не результат наблюдения с детьми.

## Учёт результата упражнения

- `correctCount` увеличивается ровно на один после первого принятого правильного ответа текущего упражнения, в том числе после предыдущих ошибочных попыток. Неверные нажатия не уменьшают этот счётчик.
- Для адаптации результат завершённого упражнения — `clean`, если ошибок не было, иначе `mistake`. Два ошибочных нажатия в одном упражнении дают один `mistake`, а не два. Правильный ответ после ошибок не превращает его в `clean`.
- Неоконченный раунд, повтор, подсказка, пауза, таймер, повторное событие подтверждения и устаревший ответ не дают отдельного результата.
- Принятый ответ учитывается даже при последующей ошибке аудиоподтверждения. Повторная загрузка или продолжение не учитывают его ещё раз.
- В новой сессии `correctCount = 0`, число вариантов — 4, серия отсутствует. Все результаты остаются только в памяти этой сессии.

## Доступность уровней и веса

| Правильных ответов до подготовки нового раунда | Цвета и числа: веса L1 : L2 : L3 | Животные: веса L1 : L2 |
| ---------------------------------------------- | -------------------------------- | ---------------------- |
| 0–2                                            | 1 : 0 : 0                        | 1 : 0                  |
| 3–7                                            | 8 : 7 : 0                        | 8 : 7                  |
| 8 и больше                                     | 40 : 35 : 25                     | 8 : 7                  |

`8 : 7` — нормировка исходных весов `40 : 35` без недоступного L3: примерно 53,3% / 46,7%. У животных L3 отсутствует всегда. Уровни после открытия не закрываются; относительные веса действуют до применения ограничения повторов. Дополнительное временное изменение весов при ошибках в первой реализации не вводится; это решение закреплено в разделе 5 ТЗ.

Повышение применяется к следующему упражнению. Третье принятое правильное решение открывает L2 для четвёртого раунда; восьмое — L3 для девятого, если раздел содержит L3.

## Адаптация числа вариантов

Уровень упражнения и число ответов изменяются независимо. Сохраняются 4, 5 и 6 ответов, включая компактные телефоны; на них уменьшается размер старших карточек по решению S01.

| Текущая ступень | Серия `clean`                | Серия `mistake` |
| --------------- | ---------------------------- | --------------- |
| 4               | 4 завершённых упражнения → 5 | 2 → остаётся 4  |
| 5               | 5 завершённых упражнений → 6 | 2 → 4           |
| 6               | остаётся 6                   | 2 → 5           |

Результат противоположного вида начинает новую серию с единицы. После изменения ступени серия сбрасывается. На нижней/верхней границе счётчик насыщается порогом соответствующей серии (2 для ошибок, 5 для успехов на ступени 6), а не растёт без ограничения. Ступень меняется только для следующего упражнения.

**N2 всегда имеет два ответа.** Его решение увеличивает `correctCount`, но не изменяет ступень или серию количества ответов: не продвигает, не сбрасывает и не прерывает её. Поэтому серия для этой адаптации означает последовательность результатов упражнений с 4–6 ответами, с пропуском N2. Это исключает влияние более высокой вероятности случайного попадания в N2 на число карточек остальных механик.

### Контрольные последовательности

Обозначения: `✓` — завершённое упражнение без ошибок, `×` — завершённое после ошибок; N2 обозначено отдельно.

| Начальное состояние      | Результаты                                              | Итог                                                  |
| ------------------------ | ------------------------------------------------------- | ----------------------------------------------------- |
| 4, без серии             | `✓ ✓ ✓ ✓`                                               | 5, без серии; L2 уже доступен                         |
| 5, без серии             | `✓ ✓ ✓ ✓ ✓`                                             | 6, без серии                                          |
| 6, без серии             | `×`                                                     | 6, серия ошибок 1                                     |
| 6, без серии             | `× ×`                                                   | 5, без серии                                          |
| 5, без серии             | `✓ × ✓`                                                 | 5, серия успехов 1                                    |
| 4, серия успехов 3       | `N2 ✓`, затем обычное `✓`                               | после N2 ещё 4 и серия 3; после обычного — 5 и сброс  |
| 5, серия ошибок 1        | `N2 ✓`, затем обычное `×`                               | после N2 ещё 5 и серия 1; после обычного — 4 и сброс  |
| 4, без серии             | две ошибки внутри одного раунда, затем правильный ответ | `correctCount + 1`, число вариантов 4, серия ошибок 1 |
| любой принятый результат | пауза, продолжение, позднее окончание аудио             | без повторного изменения счётчиков                    |

## Выбор упражнений и разнообразие

1. Определить доступные уровни по `correctCount` и механики текущего раздела.
2. Исключить недопустимые по проверенному контенту варианты. Ошибка контента должна выявляться подготовкой/валидацией; нельзя подменять её неоднозначным набором или бесконечным повторным подбором.
3. Не выбирать третий подряд одинаковый конкретный вид: `C1`, `C2`, `C3-A`, `C3-B`, `C4`, `A1`, `A2`, `A3`, `N1-A`, `N1-B`, `N1-C`, `N2`, `N3-A`, `N3-B`. Исключение — пока доступен только один вид: первые три раунда животных неизбежно используют A1. Как только появилась альтернатива, ограничение действует.
4. Удалить уровни без оставшихся видов и нормировать их веса. Затем выбрать уровень и равновероятно один из оставшихся конкретных видов этого уровня. Ограничение повторов делает фактические доли приблизительными, что соответствует ТЗ.
5. Внутри C4 чередовать перемешанные циклы трёх разрешённых шаблонов; в N2 — двух вопросов «больше/меньше»; в A2 — четырёх включённых признаков. На границе циклов не повторять последний элемент сразу, если доступна альтернатива.
6. Прямое распознавание C1/A1/N1-A сохраняет отдельные перемешанные циклы целей без повтора на стыке. Для N1-B/N1-C аналогичные отдельные циклы количеств 1–10. Формулировки прямых заданий сохраняют отдельный цикл для каждой цели, как в младшем режиме.
7. Тип счётного объекта выбирается из перемешанного цикла всех 13 типов; внутри упражнения тип, размер и цвет общие. Правильная позиция перемешивается независимо от цели и всех прочих циклов.

Источник случайности внедряется; подготовленное упражнение создаётся один раз. Повторная загрузка, неправильный ответ и смена ориентации не расходуют новые значения случайности и не меняют расположение вариантов.

## Близость количеств N2

Количество каждой группы — 1–10, группы различны, ноль не используется. Шаг между количествами выбирается отдельно от адаптации числа карточек.

- При `correctCount` 3–7 выбирается разность 4, 5 или 6, равновероятно.
- С `correctCount` 8 выбирается близкий диапазон 1–3 с весом 2 или широкий 4–6 с весом 1; внутри диапазона разность выбирается равновероятно. Простые сравнения остаются доступны.
- После выбора разности `d` меньшее значение равновероятно выбирается из `1…10−d`, большее равно ему плюс `d`. Стороны перемешиваются независимо, вопрос больше/меньше берётся из своего цикла.

Например, пара 2 и 7 допустима на начальном L2, пара 7 и 8 — после восьмого решения. Это не новый видимый уровень и не отдельная сохраняемая статистика.
