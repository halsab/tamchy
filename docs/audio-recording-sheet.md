# «Тамчы»: лист для записи двух дублей

Запись делится на **пять больших WAV-файлов**. Каждое слово или фразу нужно произнести **два раза подряд**, с тишиной между дублями и перед следующей строкой. После записи файлы будут нарезаны на отдельные фразы; для каждого клипа будет выбран лучший целый дубль по чёткости, чистоте звука и естественности склейки. Исходные длинные записи сохраняются.

Тексты и имена файлов взяты из [сценария озвучки](audio-recording-script.md), [ТЗ v2](specification.md#15-итоговая-аудиосистема) и [точного аудиореестра](../src/content/v2/audio.json). Этот лист предназначен для чтения во время записи; при изменении реестра его нужно сверить заново. Порядок строк внутри каждого мастер-файла совпадает с реестром.

## Как читать

1. В каждой строке прочитайте колонку «Дубль 1», помолчите примерно **2 секунды**, затем прочитайте «Дубль 2».
2. После второго дубля помолчите примерно **2 секунды** и переходите к следующей строке. На границе подразделов вместо этой паузы выдержите **4 секунды**.
3. В начале и конце каждого файла оставьте **4 секунды тишины**. Внутри слов и цельных фраз монтажные паузы не делайте; обычные речевые паузы по пунктуации сохраняйте.
4. Номера строк, заголовки, имена файлов, названия колонок и пояснения не произносите. «Дубль один» и «дубль два» тоже не читайте.
5. Оба дубля читайте с одной интонацией и в одном темпе. Если оговорились, выдержите 4 секунды и повторите всю строку двумя дублями; файл заново начинать не нужно. Место исправления можно отметить отдельно текстом.

Пример одной последовательности:

> Кызыл → 2 секунды тишины → Кызыл → 2 секунды тишины → Кишер сары → 2 секунды тишины → Кишер сары.

Рекомендация для всей записи: один голос, спокойный доброжелательный тон, естественный неторопливый темп. Произносите слова отчётливо, без чтения по слогам, растягивания гласных и резкого падения голоса в конце. Сохраняйте татарские звуки и точные словоформы; не заменяйте написание русской транскрипцией. Рекомендации ниже относятся к подаче и соединению фраз; ударения и фонетическая транскрипция в исходной документации не заданы.

Записывайте в одном тихом месте, с одинаковой дистанцией до микрофона и громкостью голоса. Сохраняйте исходный WAV без потерь; нарезку и подготовку коротких MP3 выполняют после выбора дублей. Каталог для пяти мастеров — `assets-source/audio/tt/`.

## Порядок этой записи

По решению владельца сначала записываются **все пять блоков без отдельной пробы**. Затем при нарезке проверяются произношение и реальные склейки, выбираются лучшие дубли. Фрагменты, у которых оба дубля не подходят, будут дозаписаны отдельно с тем же голосом, темпом и дистанцией до микрофона.

Для этой сессии предусмотренная ТЗ предварительная проверка склеек перенесена на этап после полной записи. Саму проверку нужно выполнить до использования клипов в игре.

## После записи

Для каждого клипа выбирается один лучший целый дубль: без оговорок, постороннего шума и обрезанных звуков, с подходящей для соседних клипов интонацией и громкостью. Слово не собирается из корня одного дубля и окончания другого. Если оба дубля неудачны, строка перезаписывается.

При нарезке сохраняется связь с мастер-файлом и строкой; Clip ID и имя итогового MP3 берутся из [аудиореестра](../src/content/v2/audio.json). В финальный набор попадает один MP3 на Clip ID. Длинные паузы убираются, начала и окончания звуков сохраняются; воспринимаемая громкость выравнивается. Публикуемые клипы — MP3 mono, ориентир 64–96 кбит/с; исходные WAV остаются в `assets-source/audio/tt/`.

После нарезки нужно проверить все примеры склеек из [сценария озвучки](audio-recording-script.md#19-контрольный-список-перед-записью) и прослушать результат на динамике телефона. Произношение и итоговый звук проверяет владелец; подготовка этого листа не означает, что аудиоприёмка выполнена.

Если потребуется дозапись, сохраните её отдельным WAV рядом с исходниками, например `retake-01.wav`. В сопроводительном тексте укажите исходный мастер-файл и номера повторённых строк. Каждую исправляемую строку снова произнесите дважды с теми же паузами; оригинальные пять файлов сохраняются.
