# Проверки «Тамчы»

## Объём второго этапа

Реализованы автоматические проверки чистого домена: генератор, переходы и требования к будущим адаптерам. Модуль использует настоящий каталог 4/6/5 элементов. Тесты Vitest находятся рядом с реализацией в `src/domain/game/`, выполняются в Node-окружении, без React, браузера, аудиофайлов и реальных задержек. Время передаётся числами в событиях, RNG — фиксированной последовательностью или константой.

Тесты первого этапа сохранены: схема и тексты каталога, пути, ресурсы, подготовка графики, минимальный React-корень и изолированные сборки. Команды не содержат заглушек. Реализованные здесь логические последовательности остаются модульными тестами; они не называются интеграцией с ещё отсутствующим аудиосервисом.

## Покрытые сценарии

| Область                    | Что проверяется                                                                                                                                                                  |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Генерация                  | Полные циклы для 4/6/5 элементов, границы циклов, единственность цели, различные варианты одного раздела, последовательные ID                                                    |
| Случайность                | Воспроизводимость, отдельный выбор позиции, допустимые последовательности позиций 0/0/1/1, постоянный RNG без зацикливания, границы `[0, 1)`                                     |
| Неизменность               | Замороженный каталог, прежние раунды, копирование данных сессии и события следующего раунда; рекурсивная заморозка состояний и событий в помощнике переходов                     |
| Подготовка                 | Все обязательные изображения и задание, частичная готовность, уникальный файл яблока, недопустимость ответа до фактического старта                                               |
| Правильный ответ           | Первый допустимый ответ, требование названия, отмена прежней операции, блокировка ответов и повтора; оба порядка выполнения границ 1200 и 300 мс, точный срок и срок минус 1 мс  |
| Неправильный ответ         | Однократное увеличение ошибок, тот же раунд и порядок, 249/250 мс, повтор исходного задания, подсказка после двух ошибок без автоответа                                          |
| Повторы                    | Замена операции при последовательных нажатиях, отсутствие очереди, отклонение старых стартов и окончаний в том же раунде                                                         |
| Бездействие                | 9999/10000 мс после окончания, одно напоминание, отмена по действию; ручные повторы, ошибки и паузы не сбрасывают использованное напоминание                                     |
| Гонки                      | Дубли ответов и завершений, устаревшие `sessionId`, `roundId`, `operationId`, дубли готовности файла и доставки следующего раунда                                                |
| Пауза                      | Подготовка, запрос, проигрывание и окончание задания, реакция на ошибку; все фазы подтверждения и переход; возврат без звука, продолжение с тем же раундом либо одним переходом  |
| Выход                      | Доступен из загрузки, ожидания, реакций, перехода, паузы и ошибки; поздние события не возвращают игру                                                                            |
| Ошибки                     | Картинка и задание, декодирование и запрет запуска; сохранение фазы/ресурса, явный повтор, 14999/15000 мс, новый срок новой попытки                                              |
| Подтверждение              | Ошибка загрузки, запуска и проигрывания после принятого ответа, тайм-аут, повтор без второго зачёта, отдельный срок после успешного окончания                                    |
| Отмена и декор             | Отмена не является успешным окончанием; необязательный декор и чужие ресурсы не блокируют игру                                                                                   |
| Контракт                   | Перечни ресурсов, путь названия/задания, отсутствие звука во время ожидания реакции, сроки и требования остановки                                                                |
| Длинные последовательности | По три полных цикла каждого раздела с ошибкой, повтором, паузой, правильным ответом и устаревшими callbacks; уникальные принятые раунды, сброс контекста только при новом раунде |

Проверки домена покрывают **только логическую часть** T02–T07, T09–T10 и T12 из [раздела 16 ТЗ](specification.md). Например, смена токена и требование остановки не доказывают физическую отмену звука или запроса, а переданное `AUDIO_STARTED` не доказывает слышимость записи. Полная приёмка этих T-сценариев пока не выполнена.

T01, T08 и T11 требуют игровых экранов и маршрутов. T13–T16 требуют настоящих PWA, service worker, офлайна и обновлений. T17 требует игровых экранов и проверки управления. T18 целиком не проверен: ограничения импортов домена не заменяют наблюдение за сетью и консолью готового приложения. Проверки минимального экрана первого этапа не распространяются автоматически на будущую игру.

## TDD и покрытие

Критерии сначала выражались тестами. До реализации соответствующие запуски завершались ошибкой отсутствующего модуля или несовпадением ожидаемого перехода; затем добавлялась реализация. Отдельный тест воспроизвёл исчезновение подсказки при ошибке ресурса/паузе до ответа, после чего вычисляемый признак исправлен. Тестовые ожидания ради успешного результата не ослаблялись.

`npm run test:unit -- --coverage` включает прежние области и все исходники `src/domain/game/**/*.ts`, исключая только тесты. Для каждого файла домена установлены **строки ≥90% и ветви ≥90%** через отдельный glob и `perFile: true`; покрытие других областей не компенсирует недостаток домена. Типовой `models.ts` не содержит исполняемых строк и ветвей.

Обязательность порога дополнительно проверена временным непокрытым файлом домена: команда завершилась с кодом 1 и отдельными ошибками порогов строк и ветвей именно этого файла. Проверочный файл удалён; он не входит в проект. Запреты ESLint проверены также отрицательными пробами импорта React, Node, браузерного сервиса, динамического импорта, обращения к `Date.now` и `Math.random`.

Отчёты создаются в `coverage/` и исключены из Git: таблица в консоли, HTML, JSON, JSON summary и Clover. Высокий процент не заменяет перечисленные сценарии и интеграционные проверки.

## Команды и CI

Среда — закреплённые Node.js 24.20.0 и npm 11.19.0. Последовательность проверки этапа:

```sh
npm ci
npm run format:check
npm run lint
npm run typecheck
npm run test:unit -- --coverage
npm run test:integration
npm run validate:catalog
npm run build:check
VITE_BASE=/tamchy/ npm run build:check
git diff --check
```

Существующий workflow `Проверки проекта` запускает эти npm-проверки на Linux с Node из `.nvmrc`. Новые тесты автоматически входят в существующий glob; пороги покрытия обязательны для той же команды в CI. Добавлена отдельная проверка типов домена без браузерных глобалов. Права workflow, закреплённые Actions и запрет публикации не менялись.

Технические сборки последовательно записывают `.build-check`; это неполный артефакт, который нельзя публиковать. Шесть интеграционных тестов первого этапа выполняют реальные изолированные сборки Vite и проверяют в том числе строгую блокировку неполного контента. Они не требуют наличия настоящих MP3 в репозитории и не доказывают воспроизведение.

## Результат и ограничения

Локально 7 сентября 2026 года на macOS, Node 24.20.0, npm 11.19.0: проверки этапа выполнены; 122 модульных/компонентных теста, из них 61 тест домена, и 6 интеграционных тестов успешны. Покрытие `domain/game`: строки 100%, ветви 100%, функции 100%. Полный список команд приведён выше. `npm ci` не потребовал изменения зависимостей; аудит сообщил 0 уязвимостей.

Реальные 30 обязательных учебных MP3 отсутствуют. `validate:catalog` сообщает о неполном аудиоконтенте; строгие `validate:content` и `build` сохраняют ожидаемый отказ с кодом 1. Аудиофайлы и заглушки в этом этапе не создавались. ТЗ не изменялось.

Не выполнены: игровые экраны, маршрутизация, Web Audio API, настоящие таймеры и загрузка ресурсов, PWA, офлайн, публикация. Не проверены: физическая отмена операций, касания, звук и громкость ОС, реальные Safari/iPhone/Android, сценарии установки и обновлений, Lighthouse, приёмка материалов владельцем и наблюдение за детьми. Новый workflow на GitHub в рамках локальной работы не запускался. Детали будущей интеграции и её обязательства описаны в [архитектуре](architecture.md).
