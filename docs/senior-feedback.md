# Обратная связь старшего режима: S10 и V2-05

Дата: 9 сентября 2026 года. Анализ игрового потока завершён: **существующих 12 интерактивных реплик достаточно для всех 14 конкретных видов упражнения**. Новые тексты, события и Clip ID не требуются; обязательный набор остаётся 189 MP3. Основание — назначение реплик в [разделе 13.5 ТЗ](specification.md#135-интерактивные-реплики), их утверждённые тексты в [сценарии записи](audio-recording-script.md) и проверка общего игрового потока в S10.

## События и уместность реплик

| Реплики                             | Использование и основание                                                                                                                                                                                                                                                  |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hello`, `game-start`               | Первый и последующие входы в раздел. Приветствие и начало игры не зависят от механики. Ответы открываются только с фактическим началом учебного задания.                                                                                                                   |
| `correct`, `well-done`, `very-good` | Одна похвала по кругу в нечётных раундах. Подтверждает верный выбор во всех механиках; конкретное учебное значение произносится отдельно.                                                                                                                                  |
| `think-again`, `hint`, `try-again`  | После первой, второй и третьей ошибки соответственно, затем без реплики. Предлагают подумать или повторить выбор; подходят и к предмету, и к группе, и к продолжению ряда. После каждой ошибки повторяется полное задание; со второй ошибки добавляется статичная обводка. |
| `listen`                            | Одно напоминание через 10 секунд после окончания задания. Во всех старших видах есть звуковая инструкция, поэтому предложение послушать сохраняет смысл.                                                                                                                   |
| `next-one`                          | Каждый пятый новый раунд. Переход к следующему заданию одинаков для всех видов, даже при смене механики.                                                                                                                                                                   |
| `continue`                          | Возврат после паузы до ответа, затем исходное задание. После уже принятого ответа выполняется один переход без повторного подтверждения.                                                                                                                                   |
| `goodbye`                           | Домик немедленно выводит из игры; прощание не задерживает навигацию и отменяется новым входом или скрытием страницы.                                                                                                                                                       |

Повтор не требует отдельной реплики: он отменяет текущую последовательность и запускает исходное задание. Объяснение правила и предмет вопроса уже содержатся в учебных рецептах; дополнительные интерактивные записи их дублировали бы.

## Учебное подтверждение

| Виды             | После верного выбора                                                                                                                                        |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| C1, C2, C4       | Название выбранного цвета. В C2 закрепляется цвет предмета, в C4 — цвет следующего элемента.                                                                |
| C3-A             | Цвет и название формы в обычной форме: характеристика выбранного объекта, без повторения команды найти его.                                                 |
| C3-B             | Размер, цвет и название формы в обычной форме. Все слова уже есть в конструкторе; отдельные суффиксы не склеиваются.                                        |
| A1, A2, A3       | Обычное название выбранного животного. В A2 оно связывает признак с конкретным примером; в A3 — контур с животным.                                          |
| N1-A, N1-B, N1-C | Название выбранного числа: для N1-C — количества в выбранной группе.                                                                                        |
| N2               | Название количества в правильно выбранной группе. Оно соответствует вопросу «больше» или «меньше»; название типа предмета не подменяет результат сравнения. |
| N3-A, N3-B       | Название суммы или оставшегося количества, без письменного арифметического выражения.                                                                       |

Сначала звучит предусмотренная похвала, затем учебное подтверждение. Следующий раунд ждёт одновременно 1200 мс после ответа и 300 мс после окончания учебного подтверждения. Верный выбор отмечен карточкой и отдельным знаком, поэтому подтверждение не зависит только от цвета или звука.

C3 допускает предусмотренное ТЗ визуальное подтверждение без учебной речи. Общий исполнитель поддерживает этот вариант: в чётном раунде достаточно 1200 мс, в нечётном дополнительно нужны 300 мс после прозвучавшей похвалы. Ошибка необязательной похвалы или предел ожидания 2 секунды не блокируют упражнение. Текущие генераторы C3 используют составное учебное подтверждение; автоматического переключения на визуальное при ошибке обязательного аудио нет.

## Проверка и границы вывода

Все 14 видов прошли повтор, две ошибки и подсказку, паузу, верный ответ, завершение учебного подтверждения, следующий раунд и выход в Chromium, WebKit и Firefox с настоящими MP3 и Web Audio. Тесты общего исполнителя отдельно покрывают полный порядок 12 реплик, их отмену, ошибки и визуальное подтверждение C3. Подробности и границы подмен браузерных условий записаны в [протоколе S10](testing.md#старший-режим-s10--общий-экран-и-сессия).

Это решение о достаточности текстов и событий. Оно не приписывает владельцу новую проверку произношения, естественности склеек, слышимости на телефоне или понятности ребёнку. Эти результаты остаются частью ручной приёмки; при обнаружении конкретной проблемы список дополнений можно пересмотреть отдельно.
